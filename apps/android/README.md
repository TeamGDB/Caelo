# Caelo Android prototype

Визуальный прототип VPN-клиента для Android 8–16 (API 26–36), созданный на Kotlin и Jetpack Compose.

## Сценарии

- При первом запуске показывается ввод кода доступа.
- После успешного ввода экран не показывается повторно (`SharedPreferences`).
- На главном экране можно выбрать сервер и переключить состояние подключения.
- VPN-туннель и серверная проверка кода пока не реализованы: текущая версия изолирует и демонстрирует UI.

Этот проект хранится в основном репозитории в `apps/android` как самостоятельное
нативное приложение. Он не является Flutter runner-папкой.

## Запуск

Откройте проект в Android Studio Meerkat 2024.3.1 или новее, установите Android SDK 36 и запустите конфигурацию `app`.

Либо соберите APK из терминала:

```bash
cd apps/android
./gradlew :app:assembleDebug
```

## Тесты

```bash
./gradlew testDebugUnitTest
./gradlew connectedDebugAndroidTest  # требуется запущенный эмулятор или телефон
```

Подробное описание структуры, ограничений прототипа и проверок находится в
