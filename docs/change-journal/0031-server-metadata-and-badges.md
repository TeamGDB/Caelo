# 0031 — Метаданные серверов и метки протоколов

## Почему

В ссылках VLESS флаг и вариант подключения попадали в название, а описание
терялось. Issue #174: общий список должен одинаково показывать AWG и VLESS.

## Что изменено

- Страна, имя и описание читаются отдельно; явный `tag` имеет приоритет.
  У обычной ссылки флаг становится иконкой, совпадающий суффикс транспорта
  убирается из имени. Старый кэш мигрирует без смены ID и настроек подключения.
- Все серверы получили метку протокола под обычным пингом: 9.5 pt,
  отступы 4 × 3 pt. Автовыбор без метки. TLS-варианты различимы.
- Каталог не объединяет одноимённые VLESS с разными выходами или вариантами.
- Высота заголовка шторки учитывает увеличенный системный шрифт.

## Проверка

Тесты чтения подписок и старого кэша, группировки серверов, всех меток,
выравнивания пинга и меток, узкого экрана и увеличенного шрифта.
Полный `flutter test`: 410 успешных, 8 ранее пропущенных; анализатор без замечаний.
