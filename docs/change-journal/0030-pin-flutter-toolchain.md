# 0030 — Единая версия Flutter для локальной сборки и CI

## Почему

В workflow был указан только канал `stable`. После выхода Flutter 3.50 CI
получил новый SDK, хотя Gradle 8.14, AGP 8.11.1 и Kotlin plugin 2.2.20 остались
прежними. Проверка Android-зависимостей останавливает такую сборку; анализатор
нового SDK также сообщает об устаревших импортах интерфейса и локализаций.

## Что изменено

- Flutter 3.47.9 закреплён в `.fvmrc` — на нём проверена Android-сборка ветки.
- Все установки Flutter в обычном и релизном workflow читают `.fvmrc` через
  `flutter-version-file`; версия не дублируется в шагах.
- В README описаны локальные команды FVM и запуск скриптов через `fvm exec`;
  каталог установленного SDK `.fvm/` исключён из Git.
- Переход на Flutter 3.50 остаётся отдельной миграцией сборочных инструментов
  и интерфейсных импортов. Проверки зависимостей и анализатора не отключаются.

## Проверка

- Проверка синтаксиса workflow и всех ссылок установщиков на `.fvmrc`.
- Полный workflow Flutter в PR проверяет анализатор, тесты и сборки платформ.
