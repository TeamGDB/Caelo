# 0003 — Распределение конфликтных задач по исполнителям

## Что требовалось

Распределить созданные в GitHub Project конфликтные задачи между исполнителями с учётом зон ответственности:

- `MHunterG` / Vladimir Ivanov — Go-ядро, backend и security-контракты;
- `GoldExtremal` / Artem Mandrin — визуальная часть и Flutter UI;
- пограничные архитектурные и UX-решения — совместно.

## Почему

Конфликтные задачи затрагивают разные уровни системы. Явное назначение владельцев отделяет чисто визуальные решения от core/backend-работы и обозначает места, где решение нельзя принять одной стороной без согласования контракта.

## Как было сделано

Исполнители назначены на существующие draft-задачи GitHub Project №2:

### `GoldExtremal`

- Cupertino и единый Material-подобный визуал;
- положение Settings и desktop window chrome;
- начальный язык и ручное переключение локали.

### `MHunterG`

- выбор серверов в Go-ядре;
- реальные аккаунты, администрирование, QR и backend/security вместо моковой логики Flutter.

### Совместно: `GoldExtremal` и `MHunterG`

- иерархия источников истины;
- композиция Home и центральная VPN-кнопка на границе UI и состояния core;
- поведение VPN-кнопки во время `disconnecting`.

После изменения назначения всех восьми карточек были повторно прочитаны через GitHub API и сверены с этой схемой.

## Результат

Задача решена: у каждой конфликтной карточки есть ответственный исполнитель либо оба исполнителя для совместного решения. Исходный код проекта не изменялся.
